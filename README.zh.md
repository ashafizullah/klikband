## 功能

- **时钟**：表盘风格页面，显示时间、公历和伊斯兰历日期、下一次礼拜的倒计时和进度条，以及今天的五次礼拜。屏幕默认照常熄灭；在设置中选择时钟屏幕 › 保持常亮，可让屏幕常亮，礼拜时间的振动提醒准时到达；向左滑动可快速进入礼拜后记念、早晚记念和朝向；长按可切换颜色主题（绿色、蓝色、金色、紫色、玫红、黑白），也可在设置 › 时钟主题中选择
- **伊斯兰**
  - **今日**：公历和伊斯兰历日期、下一次礼拜，以及今明两天的副功斋
  - **礼拜后记念**：按 [Rumaysho](https://rumaysho.com/1997-dzikir-setelah-shalat.html) 顺序引导计数
  - **早晚记念**：按 [Almanhaj](https://almanhaj.or.id/11518-dzikir-pagi-dan-petang.html) 顺序引导计数
  - 两者均可显示拉丁转写或阿拉伯文，宝座经文和各章经文完整显示并标注节号（[Tanzil](https://tanzil.net) 经文）
  - **礼拜时间**：采用印度尼西亚宗教部（Kemenag）算法，在设备上离线计算；在时钟、今日或礼拜时间页面打开时，到点振动并显示提示
  - **朝向**：从所在城市到天房的方向和距离，表盘上显示太阳位置，对准真实太阳即可面向朝向，并列出每年太阳直射天房的日期
  - **赞珠**：点按计数，可设 33/99/100 目标，并有振动提示
  - **伊斯兰历**：算术伊斯兰历，可手动校正 ±2 天
  - **伊斯兰节日**：8 个伊斯兰节日倒计时，按远近排序
  - **真主九十九尊名**：99 个尊名及其含义
  - **先知的祈祷**：按 [Almanhaj](https://almanhaj.or.id/83989-doa-doa-nabi-shallallahu-alaihi-wa-sallam.html) 收录先知 ﷺ 的 47 段祈祷，按记念与祈祷文字设置显示拉丁转写或阿拉伯文，附含义和辑录者
  - **副朝指南**：按 [Almanhaj](https://almanhaj.or.id/2252-tata-cara-umrah.html) 的副朝步骤，附念词及环绕/奔走圈数计数
- **通用**
  - **日历**：月历，显示伊斯兰历日期，并标注伊斯兰节日和斋戒日；点按日期查看详情
  - **倒数日**：距离或自某个日期的天数，可按月或按年重复
  - **记分牌**：双方计分：自由计分、羽毛球（21 分，三局两胜）或板式网球/网球（15-30-40、平分、盘、抢七），可撤销
  - **计数器**：最多六个计数器，可选名称（客人、人数、物品、圈数、次数）
  - **计算器**：加减乘除，支持百分比和正负号
- **设置**：城市（印度尼西亚 47 个城市，WIB/WITA/WIT 时区）、语言（印尼语、英语、中文）和记念与祈祷文字（拉丁字母或阿拉伯文）
- **关于**：应用版本、文本和计算的来源，以及设备信息（存储空间、型号、系统和平台版本）

阅读和计数页面打开时屏幕保持常亮。

## 限制

小米手环 9 没有 GPS，小米也未在该手环上开放定位（`system.geolocation`）和网络（`system.fetch`）接口。因此 KlikBand 在所有设备上都不使用这两项：所有功能均离线运行，城市需手动选择。

界面按小米手环 9 的屏幕（192×490）设计，并会适配所运行设备的屏幕：

| 设备 | 屏幕 | 布局 | 测试 |
|---|---|---|---|
| 小米手环 9 | 192×490 | 手环 | 真机 |
| 小米手环 10 | 212×520 | 手环 | Vela 模拟器 |
| 小米手环 9 Pro、8 Pro | 336×480 | 宽屏 | Vela 模拟器（9 Pro） |
| REDMI Watch 5 | 432×514 | 宽屏 | Vela 模拟器 |
| 小米 Watch S3、S4、S4 Sport、S5、S1 Pro | 圆形 466–480 | 圆形 | Vela 模拟器（S4） |

标注“Vela 模拟器”的设备尚未在真机上试过，通过 Gadgetbridge 安装的情况也可能因型号而异。欢迎反馈。

## 安装到手环

KlikBand 通过 **Android** 手机（不支持 iPhone）上的 [Gadgetbridge](https://gadgetbridge.org/) 安装。首次安装约需 30–45 分钟，并需要用一次电脑从 Mi Fitness 读取手环钥匙。之后更新只要 1 分钟。所有支持的手环和手表步骤相同。

```
npm install

```

## 项目结构

```
src/
├── manifest.json        # 应用信息和页面路由
├── common/
│   ├── i18n.js          # 界面文字（id、en、zh）和语言设置
│   ├── prayer.js        # 礼拜时间计算
│   ├── hijri.js         # 伊斯兰历换算
│   ├── cities.js        # 城市列表和城市设置
│   ├── asmaulhusna.js   # 九十九尊名数据
│   ├── duas.js          # 先知的祈祷数据
│   ├── umrah.js         # 副朝指南数据
│   ├── dhikr.js         # 礼拜后记念
│   ├── dhikrmorningevening.js  # 早晚记念
│   ├── arabicdhikr.js   # 自动生成：阿拉伯文记念 -> 图片
│   ├── arabicduas.js    # 自动生成：阿拉伯文祈祷 -> 图片
│   ├── arabic/          # 自动生成：阿拉伯文记念与祈祷图片
│   ├── fasting.js       # 副功斋与禁斋日
│   ├── holidays.js      # 伊斯兰节日日期
│   ├── calendar.js      # 月历网格
│   ├── countdown.js     # 倒数日数据与日期计算
│   ├── text.js          # 长标签滚动显示辅助函数
│   └── icons/           # 菜单图标
└── pages/               # 每个页面一个文件夹
tools/
└── arabic-images.py     # 将阿拉伯文记念与祈祷绘制为图片
```

手表无法连写阿拉伯字母，因此阿拉伯文记念与祈祷以 Amiri 字体绘制的图片显示。修改 `arabic` 文本后，先运行一次 `pip install uharfbuzz freetype-py pillow`，再运行 `python3 tools/arabic-images.py`。

如需更改默认城市，请修改 `src/common/cities.js` 中的第一项。
